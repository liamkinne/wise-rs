# Wise Platform API Rust Client

A Rust client for the Wise REST API using
[progenitor](https://github.com/oxidecomputer/progenitor).

In order to by progenitor, the v3.1 OpenAPI spec is converted by the `build.rs`
to conform to v3.0.

# Security

This code provides no guarantees around security or correctness. Use at your own
risk.
